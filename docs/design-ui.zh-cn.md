# UI / 交互设计

> 本文档描述平台界面的布局、组件结构与交互行为（"如何呈现"）。
> 通用能力定义见 `docs/spec-functional.md`。
> 具体项目以本案例（JuliaLang/julia）举例。

## 页面布局

单页布局，自上而下、左右两栏：

```
┌──────────────────────────────────────────────┐
│ 顶部导航（站点名 + 外部链接）                   │
├──────────────────────────────────────────────┤
│ 标题 + 副标题（说明 + 仓库切换）                │
├──────────────────────────────────────────────┤
│ 搜索输入框（检索 PR）                          │
├────────────────────────┬─────────────────────┤
│ 左侧：文件树            │ 右侧：PR 列表         │
└────────────────────────┴─────────────────────┘
```

## 组件结构与职责

### 顶层容器 `entry-component`
- 状态唯一持有者（仓库、分支、路径、PR 过滤）。
- 负责数据加载、URL 同步、本地偏好、分支排序、PR 定位。
- 通过属性下发、自定义事件上抛与子组件交互。

### 顶部导航
- 左侧：站点名。
- 右侧：外部链接（仓库主页等）。
- 窄屏：汉堡图标折叠。

### 标题与副标题区
- 标题：平台名 + 数据生成时间（自动刷新）。
- 副标题：说明文字 + 可用仓库切换链接。

> 举例：本案例标题为项目相关站点名，副标题区列出可用仓库切换入口；
> 数据生成时间显示"数据生成于 X 前"。

### 搜索框
- 输入框 + 重置按钮 + 解析结果展示（`#号`）。
- 支持 PR 链接 / `owner/repo#号` / 纯数字。
- 触发后上抛 `@filterchanged` 事件。

### 左侧文件树
- 顶部根节点行：仓库 + 当前分支 + 分支选择器开关。
- 递归文件夹渲染：文件夹 → 子级。
- 每个条目：图标 + 名称 + PR 计数。
- 分支选择器：`可用分支：<ul>`，点击切换。
- 名称点击 → 选中路径；图标点击 → 展开/折叠；文件夹的父路径也可被选中（聚合展示）。
- **变更状态标记**（精确定位 PR 时）：对该 PR 涉及条目，用颜色/图标区分变更类型：
  - 新增（ADDED）：绿色
  - 修改（MODIFIED）：黄色/高亮
  - 删除（DELETED）：红色
  - 重命名/移动（RENAMED）：蓝色
  - 条目不显示其他标记；未涉及该 PR 的条目保持现状。
  - 图标/颜色需在浅深主题下均清晰可辨。

### 右侧 PR 列表
- 按分支 + 路径过滤后的 PR 卡片列表。
- 过滤模式时只渲染被定位的单张卡片。

### PR 卡片
字段布局（自上而下）：
1. 标题行：状态标记（草稿/开放）+ `#号` + 标题（外链）+ 开放时长。
2. 作者行：`作者:` + 作者名（外链，高活跃作者加粗、异常作者特殊标记）。
3. 详情行：`分支:`、`里程碑:`（或 none）、`( diff | patch )` 外链。
4. 时间区：`更新:`、`创建:`（悬停含精确时间）。

## 样式与主题

- 布局样式用 CSS 变量驱动。
- **浅/深主题**：`@media (prefers-color-scheme: dark)` 自动切换。
- 字体、favicon 由平台配置（可换）。

> 举例：本案例浅色底 `#fcfcfa`、深色底 `#0d1117`，字体 Roboto，
> favicon 为仓库官方 logo（julia-dots）。

## 交互流程

- **切换分支**：文件树分支选择器 → `@branchselect` → 顶层更新分支 + 重置路径 → URL 同步 + 持久化。
- **选中路径**：点文件/文件夹名 → `@pathclick` → 顶层更新路径与关联 PR → URL 同步 → 滚动到顶。
- **搜索 PR**：输入 PR 号 → `@filterchanged` → 顶层：
  - 命中 → 切分支 + 选首个存在于文件树的文件路径 + 定位该卡片 + 标记该 PR 涉及条目的变更状态（见左侧文件树"变更状态标记"）；
  - 未命中 → 不改动当前分支/路径。
- **仓库切换**：副标题区仓库链接 → URL 写入仓库 → 整页刷新。
- **前进/后退**：`popstate` → 从 URL 恢复仓库/分支/路径/PR → 重新定位。

## 接入新项目的 UI 差异
- 顶部导航的站点名与外部链接。
- favicon（建议用仓库官方 logo）。
- 副标题的仓库切换列表。
- 具体分支命名、卡片文案（如"分支/里程碑"标签语）。
